Sanity check — latest events
SQL
Run this first every time. Confirms data is flowing and shows recent attacker activity.
sql
SELECT timestamp, event_type, src_ip, username, password
FROM cloud_siem_db.cowrie_logs
WHERE year = '2026' AND month = '08' AND day = '24'
ORDER BY timestamp DESC LIMIT 20;
Threat Intelligence
Top 20 attacking IPs
SQL
Reveals the most aggressive scanners/botnets — successes vs failures breakdown.
sql
SELECT
    src_ip,
    COUNT(*) AS total_attempts,
    COUNT(CASE WHEN event_type = 'cowrie.login.success' THEN 1 END) AS successes,
    COUNT(CASE WHEN event_type = 'cowrie.login.failed'  THEN 1 END) AS failures,
    MIN(timestamp) AS first_seen,
    MAX(timestamp) AS last_seen
FROM cloud_siem_db.cowrie_logs
WHERE event_type IN ('cowrie.login.failed', 'cowrie.login.success')
GROUP BY src_ip
ORDER BY total_attempts DESC LIMIT 20;
Most tried credential combinations
SQL
Exact username/password combos attackers spray. Great for threat intel reports.
sql
SELECT
    username, password,
    COUNT(*) AS attempts,
    COUNT(DISTINCT src_ip) AS unique_ips
FROM cloud_siem_db.cowrie_logs
WHERE event_type = 'cowrie.login.failed'
  AND username IS NOT NULL
GROUP BY username, password
ORDER BY attempts DESC LIMIT 20;
Commands run after successful login
SQL
Post-exploitation commands — recon, crypto miners, malware droppers. The gold mine.
sql
SELECT timestamp, src_ip, session_id, command
FROM cloud_siem_db.cowrie_logs
WHERE event_type = 'cowrie.command.input'
  AND command IS NOT NULL
ORDER BY timestamp DESC LIMIT 50;
Malware download attempts
SQL
file_sha = SHA256 hash — look up in VirusTotal for instant malware identification.
sql
SELECT timestamp, src_ip, session_id, file_url, file_sha, file_size
FROM cloud_siem_db.cowrie_logs
WHERE event_type = 'cowrie.session.file_download'
ORDER BY timestamp DESC;
Session Analysis
Full kill chain for one session
SQL
Reconstructs complete attacker timeline: connect → auth → commands → exit.
sql
SELECT timestamp, event_type, src_ip, username, password, command, file_url
FROM cloud_siem_db.cowrie_logs
WHERE session_id = 'REPLACE_WITH_SESSION_ID'
ORDER BY timestamp ASC;
Daily attack volume trend
SQL
Spot attack spikes by day — rising unique IPs = coordinated campaign or new botnet.
sql
SELECT
    year, month, day,
    COUNT(*) AS total_events,
    COUNT(DISTINCT src_ip) AS unique_ips,
    COUNT(CASE WHEN event_type = 'cowrie.login.success' THEN 1 END) AS successful_logins
FROM cloud_siem_db.cowrie_logs
GROUP BY year, month, day
ORDER BY year DESC, month DESC, day DESC;
